# Prakrit MT — English → Prakrit Machine Translation

A neural machine translation system for translating **English to Maharashtri Prakrit**, an ancient Indian language. The project fine-tunes [AI4Bharat's IndicTrans2](https://github.com/AI4Bharat/IndicTrans2) (1B parameter, English → Indic) on a parallel English–Prakrit corpus and evaluates translations using BLEU scores.

## Highlights

- **Base model:** `ai4bharat/indictrans2-en-indic-1B` (Hugging Face)
- **Fine-tuning toolkit:** [IndicTrans2 finetuning scripts](https://github.com/AI4Bharat/IndicTrans2) (cloned as a submodule / local directory)
- **Training data:** ~1 300 parallel sentence pairs (Maharashtri Prakrit ↔ English)
- **Evaluation:** 100-sentence held-out test set scored with [SacreBLEU](https://github.com/mjpost/sacrebleu)
- **Iterative back-translation:** reversed (English → Prakrit) data is included to augment training

## Getting Started

### Prerequisites

| Requirement | Notes |
|---|---|
| Python ≥ 3.9 | Tested with 3.10+ |
| CUDA GPU | Fine-tuning requires ≥ 36 GB GPU memory; inference ≥ 24 GB |
| Hugging Face account | For downloading the base model (set `HF_TOKEN`) |

### 1. Clone the repository

```bash
git clone https://github.com/samarth-gandhii/Prakrit_MT.git
cd Prakrit_MT
```

### 2. Set up the IndicTrans2 toolkit

Clone the AI4Bharat fine-tuning/inference scripts into the project root:

```bash
git clone https://github.com/AI4Bharat/IndicTrans2.git \
    finetuning_and_inferencing_using_indictrans2_models
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

> [!NOTE]
> `IndicTransToolkit` is listed in `requirements.txt` and may need to be installed from [its GitHub repo](https://github.com/AI4Bharat/IndicTransToolkit) if it is not on PyPI.

### 4. (Optional) Download the tokenizer locally

```bash
python download_tokenizer.py
```

## Usage

### Fine-tuning

Fine-tune IndicTrans2 on the Prakrit parallel corpus:

```bash
python run_finetune.py \
    --epoch 30 \
    --model-dir models/eng_to_prakrit_v5 \
    --train data/final_train_clean.tsv \
    --test-size 0
```

**Key arguments:**

| Flag | Default | Description |
|---|---|---|
| `--epoch` | 5 | Number of training epochs |
| `--model-dir` | `models/eng_to_prakrit_v3` | Directory to save checkpoints |
| `--train` | `data/final_train_clean.tsv` | TSV file with `prakrit\tenglish` columns |
| `--base-model` | `ai4bharat/indictrans2-en-indic-1B` | HF model ID or local path |
| `--test-size` | 0.1 | Fraction of data held out for validation |
| `--local-files-only` | — | Load model/tokenizer only from local cache |

**On an HPC cluster (SLURM):**

```bash
sbatch scripts/slurm_finetune.sh
```

### Inference

Generate translations with the fine-tuned model:

```bash
python run_inference.py \
    --model-dir models/eng_to_prakrit_v5-final \
    --output inferences/eng_to_prakrit_v5.txt
```

Or with the baseline (un-tuned) model:

```bash
python run_inference_baseline.py \
    --output inferences/eng_to_prakrit.baseline.txt
```

### Evaluation

Compute the BLEU score between a hypothesis file and the reference:

```bash
python run_bleu.py \
    --hyp inferences/eng_to_prakrit_v5.txt \
    --ref data/100_test_pra.txt
```

```
                   │ (reversed data)  │
                   └──────────────────┘
```

## Data Format

The training TSV files use a simple two-column format with a header row:

```
prakrit	english
पसुवइणो रोसारुण...	Bow before Siva's offering to Twilight...
```

The reversed file swaps the columns (`english\tprakrit`) for iterative back-translation.
